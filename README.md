# 🚀 Slow Rockets

A lightweight **Fabric mod** that specifically nerfs **Elytra firework boost speed** without changing normal Elytra gliding.  
Perfect for servers or worlds that want to balance Elytra travel without removing rockets entirely.

---

## ✨ What It Does

**Slow Rockets** reduces *only* the firework boost applied to Elytra flight.

- Normal Elytra gliding speed stays **100% vanilla**
- Only the **acceleration from fireworks** is slowed
- Displays a short **action-bar message** with a cooldown for extra feedback

---

## 🧩 Features

- 🚀 Reduces Elytra firework boost speed by **~80%**
- 🕊️ Leaves normal Elytra gliding speed unchanged
- 💬 Action-bar messages with a cooldown
- 🔒 Optional server enforcement: block clients without the mod

---

## 📦 Requirements

- **Minecraft** 1.21.11  
- **Fabric Loader**  
- **Fabric API**  
- **Java** 21  

---

## 🖥️ Client vs Server

- **Client only**  
  Install on the client if you just want the boost nerf locally.

- **Client + Server**  
  Install on both if you want to **require the mod to join a server**.

---

## 🔧 Installation

1. Install **Fabric Loader** and **Fabric API** for Minecraft 1.21.11  
2. Drop the `SlowRockets.jar` into your `mods` folder  
3. Restart Minecraft (and the server, if applicable)

---

## 🔗 Compatibility

Designed for **Fabric 1.21.11**.  
Works alongside most mods without issues.
